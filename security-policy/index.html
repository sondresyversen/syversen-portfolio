Security Policy

I take security seriously and appreciate responsible disclosure of any vulnerabilities.

How to Report

If you find a security issue, please email:

security@syversen.dev

What to Include

  • Description of the issue
  • Steps to reproduce
  • Any screenshots or proof of concept (if possible)

Response Time

I aim to respond within 3–7 days and will work to fix valid issues as quickly as possible.

Scope

This policy applies only to this personal portfolio website and its hosted content.

Cloudflare Turnstile

This website uses Cloudflare Turnstile, a spam and abuse prevention service provided by Cloudflare. Turnstile may collect limited technical data (such as browser and interaction data) to determine whether a visitor is a human or a bot. This processing is governed by Cloudflare’s Privacy Policy and the Turnstile Privacy Addendum.

Thank you for helping improve security.
